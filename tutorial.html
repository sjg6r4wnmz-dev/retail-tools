稽核闭环

选门店 → 逐条整改 → 签名确认 → 自动归档

立即使用 →
1 使用步骤
🔍
搜索门店
输入店名、城市或区经理名字，快速找到要整改的门店
💡 搜索结果会显示该店有几份稽核、扣分多少项，一眼就知道要不要改
📋
选择稽核记录
同一家店可能被零售组和运营各打了一次，选择你要整改的那份
💡 红色标签=零售组稽核，蓝色标签=运营稽核，标注了提交人、日期、分数
✏️
逐条整改
每条扣分点单独展开，选择「已整改」或「不能立即整改」，可拍照留证
💡 选「不能立即整改」时需填预计完成时间；已提交的扣分点会置灰标记「✓」
✍️
签名确认
整改完成后在底部手写签名，一次签名覆盖该门店所有扣分点
💡 先填顶部「提交人」姓名再开始整改，系统会记录到表格
2 新旧方式对比
旧方式（收集码+手动填表） 新方式（稽核闭环工具）
操作入口 扫码填表单 → 再打开稽核表手动对应 一个链接搞定，不用切平台
扣分点来源 ✗ 自己翻稽核表找扣了什么 ✓ 自动拉取，逐条展示
整改方式 ✗ 一条一条在表格里找行填 ✓ 卡片式逐条整改，点开即填
整改照片 ✗ 表单传或表格传，容易脱节 ✓ 每条扣分点直接拍照，自动关联
责任人签名 ✗ 无，无法追溯 ✓ 手写签名+提交人姓名，有据可查
多份稽核 ✗ 分不清零售组/运营各打的 ✓ 自动区分，可选择整改哪份
数据同步 ✗ 手动复制粘贴到表格 ✓ 自动同步到钉钉AI表格
管理后台 ✗ 填错了只能去表格改 ✓ 独立后台，可编辑/删除记录
数据更新 ✗ 手动导出，容易遗漏 ✓ 每天凌晨6点自动更新当月稽核
操作耗时 ✗ 一家店约10-15分钟 ✓ 一家店约3-5分钟
3 核心优势
🔗
闭环一体，不再两头跑
以前收集码填完还要回稽核表手动对应填写，现在选门店→看扣分→整改→签名→自动入表，全在一个页面完成
📋
扣分点自动带出，不遗漏
直接从当月稽核数据拉取每一条扣分项，逐条卡片展示，改一条划掉一条，漏没漏一目了然
🏷️
零售组/运营稽核自动区分
同一家店被打了多次稽核？自动标注是谁打的、哪个组的，你可以选择先改哪份
📷
照片直关联扣分点
每条扣分点可单独拍照上传，照片和扣分项自动绑定，不再出现照片找不到对应的问题
✍️
签名+姓名，责任到人
手写签名确认整改结果，提交人姓名自动记录，谁改的、改了什么、什么时候改的，全可追溯
⚡
自动同步，实时可查
提交后3分钟内自动同步到钉钉AI表格，统筹人直接在表格看全部记录，不用等
4 管理后台（仅统筹人使用）
🔧 独立管理页面
统筹人可在管理后台查看所有提交记录、编辑（如填错店名）、删除记录。密码登录，操作安全。
进入管理后台 →
📌
